# 1. 计划/任务（核心功能）

## 1.1 获取计划列表

**接口名称**: `getAll()`

**请求方式**: `GET`

**请求路径**: `/plans`

**查询参数**:
- `userId` (可选): 用户ID

**返回值**: `Plan[]`

### Plan 对象格式

```typescript
{
  "id": string,              // 计划ID
  "title": string,           // 计划名称
  "totalDays": number,       // 打卡周期（总天数）
  "completedDate": string[], // 已打卡日期列表（格式：'YYYY-MM-DD'）
  "type": 0 | 1 | 2,        // 打卡方式：0-盖章打卡, 1-数值记录, 2-文字日记
  "remindSetting": [         // 提醒设置
    {
      "time": string,        // 提醒时间（HH:mm）
      "status": boolean      // 提醒状态：true-开启, false-关闭
    }
  ],
  "rewords": [               // 阶段里程碑/奖励
    {
      "times": number,       // 成就条件（累计天数）
      "title": string,       // 成就名称
      "description": string, // 成就奖励/描述
      "status": boolean      // 解锁状态
    }
  ],
  "icon": string,            // 计划图标名（MaterialIcons）
  "color": string,           // 计划卡片主题颜色（可选）
  "currentDays": number,     // [派生] 当前已累计打卡天数
  "progress": number,        // [派生] 进度百分比 (0-100)
  "days": number             // [派生/兼容] 已打卡天数
}
```

## 1.2 获取单个计划详情

**接口名称**: `getById()`

**请求方式**: `GET`

**请求路径**: `/plans/:id`

**查询参数**:
- `userId` (可选): 用户ID

**返回值**: `Plan`

## 1.3 创建新计划

**接口名称**: `create()`

**请求方式**: `POST`

**请求路径**: `/plans`

**查询参数**:
- `userId` (可选): 用户ID

**请求体**: `Omit<Plan, 'id'>` (不含 id 的 Plan 对象)

**返回值**: `Plan`

## 1.4 更新计划

**接口名称**: `update()`

**请求方式**: `PUT`

**请求路径**: `/plans/:id`

**查询参数**:
- `userId` (可选): 用户ID

**请求体**: `Partial<Plan>` (部分 Plan 字段)

**返回值**: `Plan`

## 1.5 删除计划

**接口名称**: `delete()`

**请求方式**: `DELETE`

**请求路径**: `/plans/:id`

**查询参数**:
- `userId` (可选): 用户ID

**返回值**: `{ success: boolean }`

## 1.6 计划打卡

**接口名称**: `checkIn()`

**请求方式**: `POST`

**请求路径**: `/plans/:id/check-in`

**查询参数**:
- `date`: 打卡日期 (string, 'YYYY-MM-DD')
- `userId` (可选): 用户ID

**返回值**: `Plan` (更新后的计划对象)

# 2. 发现圈子（社交与动态）

## 2.1 获取圈子/动态列表

**接口名称**: `getAll()`

**请求方式**: `GET`

**请求路径**: `/circles`

**返回值**: `CircleListItem[]` (包含 CircleMoment 和 CircleTopic 两种类型)

### CircleMoment (瀑布流动态) 对象格式

```typescript
{
  "id": string,              // 动态ID
  "title": string,           // 标题
  "description": string,     // 简短描述（列表展示用）
  "content": string,         // 详细内容（详情页展示用）
  "type": "waterfall",       // 固定为瀑布流类型
  "members": string,         // 参与人数描述（如 "1.2k"）
  "imageUri": string,        // 封面图（列表展示用）
  "images": string[],        // 所有图片链接列表（详情页展示用）
  "authorName": string,      // 作者昵称
  "authorAvatarUri": string, // 作者头像
  "likes": number,           // 点赞数
  "commentsCount": number,   // 评论数
  "comments": Comment[],     // 评论列表（仅详情接口返回）
  "isLiked": boolean,        // 当前用户是否已点赞
  "isCollected": boolean,    // 当前用户是否已收藏
  "category": string         // 分类/话题名称（可选）
}
```

### CircleTopic (话题卡片) 对象格式

```typescript
{
  "id": string,                    // 话题ID
  "title": string,                 // 话题标题
  "description": string,           // 话题描述（如 "已有 124 位岛友分享了他们的答案"）
  "type": "topic",                 // 固定为话题类型
  "members": string,               // 参与人数描述（如 "124"）
  "topicTag": string,              // 话题标签 (如 "精选话题")
  "participantsAvatars": string[], // 参与者头像预览列表（最多3个）
  "backgroundColor": string        // 卡片背景色
}
```

### Comment (评论) 对象格式

```typescript
{
  "id": string,              // 评论ID
  "userName": string,        // 评论者昵称
  "userAvatarUri": string,   // 评论者头像（可选）
  "text": string,            // 评论内容
  "time": string             // 评论时间（如 "2小时前"）
}
```

## 2.2 获取圈子详情

**接口名称**: `getById()`

**请求方式**: `GET`

**请求路径**: `/circles/:id`

**返回值**: `CircleDetail` (包含完整的 comments 数组和所有字段)

## 2.3 加入圈子

**接口名称**: `join()`

**请求方式**: `POST`

**请求路径**: `/circles/:id/join`

**返回值**: `{ success: boolean }`

## 2.4 发布新动态

**接口名称**: `createMoment()`

**请求方式**: `POST`

**请求路径**: `/circles`

**请求体格式**:

```typescript
{
  "title": string,        // 标题
  "description": string,  // 简短描述
  "content": string,      // 详细内容
  "images": string[],     // 图片URL列表
  "category": string,     // 分类（可选）
  "imageUri": string      // 封面图（可选，默认取 images[0]）
}
```

**返回值**: `CircleMoment`

## 2.5 上传图片

**接口名称**: `uploadImage()`

**请求方式**: `POST`

**请求路径**: `/circles/upload`

**请求体**: FormData (图片文件)

**返回值**: `{ url: string }` (上传后的图片URL)

## 2.6 点赞动态

**接口名称**: `likeCircle()`

**请求方式**: `POST`

**请求路径**: `/circles/:id/like`

**返回值**: `{ success: boolean }`

## 2.7 取消点赞

**接口名称**: `unlikeCircle()`

**请求方式**: `DELETE`

**请求路径**: `/circles/:id/like`

**返回值**: `{ success: boolean }`

## 2.8 收藏动态

**接口名称**: `collectCircle()`

**请求方式**: `POST`

**请求路径**: `/circles/:id/collect`

**返回值**: `{ success: boolean }`

## 2.9 取消收藏

**接口名称**: `uncollectCircle()`

**请求方式**: `DELETE`

**请求路径**: `/circles/:id/collect`

**返回值**: `{ success: boolean }`

## 2.10 获取热门话题列表

**接口名称**: `getTrendingTopics()`

**请求方式**: `GET`

**请求路径**: `/circles/topics/trending`

**返回值**: `string[]` (话题标签列表)

## 2.11 获取附近推荐地点

**接口名称**: `getNearbyLocations()`

**请求方式**: `GET`

**请求路径**: `/circles/locations/nearby`

**返回值**: 
```typescript
Array<{
  name: string,    // 地点名称
  sub: string,     // 副标题/详细地址
  id: string       // 地点ID
}>
```

---

**注意事项：**
- 后端返回字段建议使用蛇形命名（如 `author_name`），前端会通过 Mapper 自动转换为驼峰命名（如 `authorName`）
- `isLiked` 和 `isCollected` 字段需要后端根据当前登录用户返回
- 评论列表 `comments` 仅在详情接口 `/circles/:id` 中返回，列表接口只返回 `commentsCount`

# 6. 日历与打卡

## 6.1 获取日历数据

**接口名称**: `getData()`

**请求方式**: `GET`

**请求路径**: `/calendar`

**查询参数**:
- `year`: 年份 (number)
- `month`: 月份 (number, 1-12)
- `userId` (可选): 用户ID

**返回值**: `DayData[]`

## 6.2 获取今日金句

**接口名称**: `getDailyQuote()`

**请求方式**: `GET`

**请求路径**: `/calendar/quote`

**返回值**: 
```typescript
{
  "text": string,    // 金句内容
  "author": string   // 作者
}
```

## 6.3 更新日历活动

**接口名称**: `updateDay()`

**请求方式**: `PATCH`

**请求路径**: `/calendar`

**请求体**:
```typescript
{
  "day": number,
  "hasActivity": boolean,
  "activityType": "primary" | "secondary" | "tertiary"  // 可选
}
```

**返回值**: `{ success: boolean }`

### DayData 对象格式

```typescript
{
  "day": number,                    // 日 (1-31)
  "hasActivity": boolean,           // 当天是否有打卡记录
  "isToday": boolean,               // 是否为今天
  "isSelected": boolean,            // 是否被选中（前端状态）
  "activityType": "primary" | "secondary" | "tertiary",  // 活动类型（可选）
  "completedPlanIds": string[]      // 当天完成的计划ID列表（可选）
}
```

## 通用响应格式

所有接口返回统一的响应格式：

```typescript
{
  "success": boolean,     // 请求是否成功
  "data": T,             // 返回数据（泛型）
  "error": string,       // 错误信息（可选）
  "message": string      // 提示信息（可选）
}
```

## 错误码说明

- `200`: 成功
- `400`: 请求参数错误
- `401`: 未授权
- `404`: 资源不存在
- `500`: 服务器内部错误
