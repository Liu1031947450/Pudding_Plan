# 任务首页页面接口

## 1. 获取任务列表

**接口名称**: `getTasks()`

**请求方式**: `GET`

**请求路径**: `/tasks`

**返回值**: 任务列表 `[Task[]]`

### Task 对象格式

```json
{
  "id": number,           // 任务ID
  "title": string,        // 计划名称
  "total_time": string,   // 打卡周期（天）
  "type": number,         // 打卡方式：0-盖章打卡, 1-数值记录, 2-文字日记
  "remindSetting": [             // 提醒设置
    {
      "time": string,     // 提醒时间（HH:mm）
      "status": boolean   // 提醒状态：true-开启, false-关闭
    }
  ]
}
```
