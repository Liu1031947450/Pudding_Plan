# 任务首页页面接口

## 1. 获取任务列表

**接口名称**: `getTasks()`

**请求方式**: `GET`

**请求路径**: `/tasks`

**返回值**: 任务列表 `[Task[]]`

### Task 对象格式

```json
{
  "id": string,           // 任务ID
  "title": string,        // 计划名称
  "totalDays": number,    // 打卡周期（总天数）
  "currentDays": number,  // 当前打卡天数
  "type": number,         // 打卡方式：0-盖章打卡, 1-数值记录, 2-文字日记
  "remindSetting": [      // 提醒设置
    {
      "time": string,     // 提醒时间（HH:mm）
      "status": boolean   // 提醒状态：true-开启, false-关闭
    }
  ],
  "rewords": [            // 阶段里程碑
    {
      "times": number,    // 成就条件（天数）
      "title": string,    // 成就名称
      "description": string, // 成就奖励
      "status": boolean   // 成就状态：true-已解锁, false-未解锁
    }
  ],
  "icon": string          // 计划图标
}
```

## 2. 获取用户成就列表

**接口名称**: `fetchBadges()`

**请求方式**: `GET`

**请求路径**: `/badges`

**返回值**: 成就列表 `[Badge[]]`

### Badge 对象格式

```json
{
  "id": string,           // 成就ID
  "title": string,        // 成就名称
  "description": string,  // 成就描述
  "icon": string,         // 成就图标（MaterialIcons图标名）
  "color": string,        // 成就颜色
  "unlocked": boolean     // 解锁状态：true-已解锁, false-未解锁
}
```
